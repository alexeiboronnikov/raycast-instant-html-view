# How to Install it
1. Make it executable: ⁠chmod +x instant-html-view.sh 	
2. In Raycast, open Settings → Script Commands → Add Script Directory and pick the folder that contains the script.
3. 3.	In Root Search, find Open HTML Preview, press ⁠⌘K, choose Configure Command, then Record Hotkey.
After that: copy HTML source, press the hotkey. Raycast runs the script even when it is not open.
